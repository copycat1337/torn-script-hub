Torn Pickpocket Helper — ranks each target with a number by difficulty, marks the best-paying targets with $$$, and highlights the best targets in green. Blinks and shows a tooltip when a target's optimal condition is met for a rare item (e.g. Jogger walking → Crocozade). Uses DOM only to inject highlights, data sourced from the Torn wiki, no API needed. Works on desktop (OC/Chrome) and Torn PDA
